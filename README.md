# 🔺 Тригонометрия — Интерактивный сайт

Интерактивный сайт для изучения тригонометрии с динамическим тригонометрическим кругом.

## 🚀 Как запустить

```bash
# Установить зависимости
npm install

# Запустить в режиме разработки
npm start
```

Открой браузер на `http://localhost:3000`

## 📦 Сборка для GitHub Pages

```bash
npm run build
```

Затем залей папку `build/` на GitHub Pages.
